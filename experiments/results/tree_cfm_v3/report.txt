WHY v3 IS FAIRER THAN v2
------------------------
v2 used learnable nn.Embedding for all methods -> both OldMethod and
NewMethod had extra trainable params in the embedding. Difference in
performance could be due to embedding quality, not time-conditioning.

v3 uses a FIXED sinusoidal TreePosEnc (0 trainable params):
  OldMethod: only velocity MLP trains (pos_enc is frozen buffer)
  NewMethod: velocity MLP + ContextTimeEmb trains (~1.5K extra params)
  The only structural difference is whether t is fused with pos_enc.

FIXED POSITIONAL ENCODING: TreePosEnc
--------------------------------------
For each branch c, encodes its child-index path from root:
  path[c] = [k1, k2, k3, k4]  where kd = child position at depth d
  encode(kd) = [sin(kd/2 * pi * f) for f in [1,2,4,8]]
               + [cos(kd/2 * pi * f) for f in [1,2,4,8]]
  -> 2*4 dims/level * 4 levels = 32 dims total, NO training
